# Workout Library

A dark, responsive workout library where users can browse exercises and build a personal workout plan.

## Technologies

- Next.js 16 and React 19
- TypeScript
- Tailwind CSS and daisyUI
- React Toastify
- Context API with localStorage persistence

## Key Features

- Browse workout cards and open detailed exercise pages.
- Add exercises to today's plan with a five-workout limit.
- Save workouts for later in a separate tab.
- View live exercise, duration, and calorie statistics for each tab.
- Sort the active list by duration, calories, or rating.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
